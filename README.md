# lanelis-assets

Статические файлы сайта [lanelisapp.com](https://lanelisapp.com) — стили, скрипт,
шрифты и картинки. Отдаются через GitHub Pages.

Зачем отдельно: российские сети режут отдачу с клиентских адресов Cloudflare
после первых ~20 КБ на соединение, из-за чего таблица стилей и фон не доходили
до посетителей никогда. GitHub Pages стоит на собственных адресах GitHub
(185.199.x) и этой блокировкой не затронут.

Файлы собираются генератором в основном репозитории и копируются сюда.
Править их здесь руками не нужно.
